# 忍者之路 Online

原創忍者題材的 3D 開放世界網頁遊戲，使用 [Three.js](https://threejs.org/)。電腦（鍵盤滑鼠）和手機（觸控）都能玩。

玩家扮演「風鈴之里」的新任下忍，在蒼穹之國的森林、河川與山岳間自由探索。

## 執行

需要 [Node.js](https://nodejs.org/)，不用安裝任何套件。

```bash
node serve.js
```

開啟 http://localhost:5173 。終端機也會列出區網網址，手機連同一個 Wi-Fi 就能玩。Windows 可以直接雙擊 `start.bat`。

### 成長

- **等級**：擊敗敵人得到經驗值。每升一級獲得 3 能力點、1 忍術點，HP 與查克拉回滿。
- **階級**：下忍 → 中忍（Lv5）→ 上忍（Lv10）→ 精英上忍（Lv15）→ 傳說忍者（Lv20）
- **能力值**：體力（HP）、查克拉（上限與回復）、體術（體術與苦無傷害）、忍術（忍術傷害）、敏捷（移動速度）
- **查克拉屬性**：Lv3 選第一個、Lv12 選第二個。各屬性有兩招，用忍術點學習。
- **熟練度**：同一招每用 10 次升一星（最多五星），傷害 +6%、耗費 -4%。
- **金錢與商店**：敵人會掉「兩」。廣場東側的忍具店賣傷藥、兵糧丸與裝備；西側鈴屋拉麵 20 兩一碗，HP 與查克拉全滿。
- **存檔**：自動存在瀏覽器（每 15 秒、升級與購買時）。

### 任務與劇情

首領塔前的**任務板**可以接任務（一次最多 3 個），完成目標後回任務板回報領取報酬。旁邊的**天守大人**會帶出主線劇情：叛忍「黑鴉」偷走了村子的禁術卷軸。

| 等級 | 任務 | 目標 | 開放條件 |
|---|---|---|---|
| D | 修行的成果 | 攻擊訓練木樁 20 次 | — |
| D | 巡視白鷺川 | 前往白鷺川 | — |
| D | 驅逐野狼（可重複） | 擊敗野狼 5 隻 | — |
| D | 拉麵外送 | 和南方道路的旅人說話 | Lv2 |
| C | 山賊討伐（可重複） | 擊敗山賊 6 名 | Lv4、完成驅逐野狼 |
| C | 森林之王 | 擊敗狼王 | Lv5、完成驅逐野狼 |
| B | 流浪忍者的情報（可重複） | 擊敗流浪忍者 3 名 | Lv7、完成山賊討伐 |
| A | 黑鴉 | 擊敗黑鴉 | Lv10、完成流浪忍者的情報，向天守大人接取 |

村民可以對話，會給你遊戲提示。頭上有「！」的 NPC 有新消息。

### 敵人

| 敵人 | 出沒地點 | 特徵 |
|---|---|---|
| 野狼 | 西邊森林 | 速度快、成群行動，打一隻整群都會撲上來 |
| 山賊 | 南方道路與郊外 | 揮刀前會舉高，動作慢但很痛 |
| 流浪忍者 | 河邊與山區 | 會丟苦無，也會用替身術閃避 |
| 訓練木樁 | 村子大門外 | 不會反擊，用來練習 |
| **狼王**（頭目） | 幽冥森林最深處 | 體型巨大，會嚎叫召喚狼群 |
| **黑鴉**（頭目） | 北方山區 | 扇形苦無、火球，血量剩一半時叫出影子分身 |

頭目在小地圖上是金色圓點，只有重擊（三連擊最後一下、忍術擊退）或暈眩才能打斷它們的動作。

敵人出手前身體會閃紅光，看到就用替身術閃開。

## 專案結構

```
src/
├── main.js          遊戲主迴圈
├── data/theme.js    世界觀設定：地名、角色名、招牌文字、主角外觀
├── core/            輸入、數學、畫質設定、文字貼圖
├── combat/          戰鬥：體術、苦無、結印與忍術（jutsu.js）、敵人 AI、分身
├── progress/        成長：等級、能力值、道具、存檔
├── quests/          任務表與任務進度
├── render/          賽璐璐材質、描邊後製、風
├── world/           地形、水、草、樹、村莊、天空、碰撞
├── player/          主角控制、角色模型與動畫、鏡頭
├── npc/             村民
├── fx/              粒子特效
└── ui/              介面、小地圖、觸控操作
```

### 自訂世界觀

所有名稱集中在 `src/data/theme.js`。想在自己電腦上換成別的設定，複製成 `src/data/theme.local.js`，只寫要改的欄位即可。這個檔案列在 `.gitignore`，不會被上傳；網址加上 `?original` 可以暫時切回預設設定。
