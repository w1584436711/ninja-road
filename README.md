# 忍者之路 Online

原創忍者題材的 3D 開放世界網頁遊戲，使用 [Three.js](https://threejs.org/)。電腦（鍵盤滑鼠）和手機（觸控）都能玩。

玩家扮演「風鈴之里」的新任下忍，在蒼穹之國的森林、河川與山岳間自由探索。

## 執行

需要 [Node.js](https://nodejs.org/)，不用安裝任何套件。

```bash
node serve.js
```

開啟 http://localhost:5173 。終端機也會列出區網網址，手機連同一個 Wi-Fi 就能玩。Windows 可以直接雙擊 `start.bat`。

## 操作

| 電腦 | 手機 | 功能 |
|---|---|---|
| WASD | 左半邊拖曳（搖桿） | 移動 |
| Shift | 搖桿推到底 | 忍者跑 |
| Space | 跳 | 跳躍、空中再按二段跳 |
| 左鍵 / F | 攻 | 體術三連擊（第三下把敵人踢飛） |
| Q | 苦 | 投擲苦無 |
| R | 鎖 | 鎖定敵人 |
| X | 替 | 替身術：閃避並留下木頭，鎖定中會繞到敵人背後 |
| 1–4 | 寅 巳 未 辰 | 結印，依序按出就發動忍術 |
| E | 迅 | 迅影步（衝刺） |
| C（按住） | 蓄 | 聚集查克拉 |
| 滑鼠 / 滾輪 | 右半邊滑動 / 雙指捏合 | 轉動視角 / 縮放 |
| T | 點時鐘 | 快轉一小時 |

有查克拉時可以在水面上奔跑；查克拉用完會掉進水裡。

### 忍術

| 忍術 | 結印 | 查克拉 | 效果 |
|---|---|---|---|
| 爆炎球 | 巳 → 寅 | 25 | 火球，命中後爆炸造成範圍傷害 |
| 分身術 | 未 → 巳 → 寅 | 30 | 召喚兩個分身協同作戰 15 秒，被打一下就消失 |
| 裂風刃 | 辰 → 未 | 20 | 前方扇形風刃，擊退所有敵人 |

### 敵人

| 敵人 | 出沒地點 | 特徵 |
|---|---|---|
| 野狼 | 西邊森林 | 速度快、成群行動，打一隻整群都會撲上來 |
| 山賊 | 南方道路與郊外 | 揮刀前會舉高，動作慢但很痛 |
| 流浪忍者 | 河邊與山區 | 會丟苦無，也會用替身術閃避 |
| 訓練木樁 | 村子大門外 | 不會反擊，用來練習 |

敵人出手前身體會閃紅光，看到就用替身術閃開。

## 專案結構

```
src/
├── main.js          遊戲主迴圈
├── data/theme.js    世界觀設定：地名、角色名、招牌文字、主角外觀
├── core/            輸入、數學、畫質設定、文字貼圖
├── combat/          戰鬥：體術、苦無、結印與忍術、敵人 AI、分身
├── render/          賽璐璐材質、描邊後製、風
├── world/           地形、水、草、樹、村莊、天空、碰撞
├── player/          主角控制、角色模型與動畫、鏡頭
├── npc/             村民
├── fx/              粒子特效
└── ui/              介面、小地圖、觸控操作
```

### 自訂世界觀

所有名稱集中在 `src/data/theme.js`。想在自己電腦上換成別的設定，複製成 `src/data/theme.local.js`，只寫要改的欄位即可。這個檔案列在 `.gitignore`，不會被上傳；網址加上 `?original` 可以暫時切回預設設定。
