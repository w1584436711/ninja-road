# 忍者之路 Online

原創忍者題材的 3D 開放世界網頁遊戲，使用 [Three.js](https://threejs.org/)。電腦（鍵盤滑鼠）和手機（觸控）都能玩。

玩家扮演「風鈴之里」的新任下忍，在蒼穹之國的森林、河川與山岳間自由探索。

### 世界

1600×1600 公尺。村子在正中央，被一圈山脈圍住，有三個山口通往外面：

| 地區 | 位置 | 特色 |
|---|---|---|
| 風鈴之里 | 中央 | 村子、首領塔、任務板、商店 |
| 白鷺川 | 村子東邊 | 由北往南流進大海的河 |
| 幽冥森林 | 村子西邊 | 野狼、狼王 |
| **蒼龍峽** | 沿白鷺川往北 | 赭紅色岩層的峽谷，崖山賊出沒 |
| **霧鳴瀑布** | 峽谷盡頭 | 從高原落下的大瀑布，有水霧與彩虹 |
| **雲上高原** | 瀑布上方 | 溪水流向瀑布的高原，魔狼與崖山賊 |
| **潮見海岸** | 南方道路的盡頭 | 沙灘與大海，海賊 |
| **古樹之森** | 西方山口外 | 巨木林立的森林，魔狼群 |
| **東方原野** | 東方山口外 | 起伏的原野 |

各地有**驛站**（頂端飄著水晶的石燈籠）：走到旁邊就會登記，之後在任何一座驛站都能傳送過去。村子大門外的驛站一開始就能用。按 **M**（手機點小地圖）打開大地圖。

靠近瀑布、河邊或海邊會聽到水聲與海浪聲。

## 執行

需要 [Node.js](https://nodejs.org/)，不用安裝任何套件。

```bash
node serve.js
```

開啟 http://localhost:5173 。終端機也會列出區網網址，手機連同一個 Wi-Fi 就能玩。Windows 可以直接雙擊 `start.bat`。

有查克拉時可以在水面上奔跑；查克拉用完會掉進水裡。

移動接近真人速度：慢走 2.3 m/s、跑步 6.5 m/s，忍者跑 15 m/s。腳步依地面材質（石板、泥土、草地、沙、木頭、水）發出不同聲音；體術、苦無、結印、每種忍術、爆炸、頭目嚎叫、升級也都有音效，越遠越小聲。全部即時合成，不需要音檔。開始畫面可以關閉音效。

背景音樂也是即時合成的和風小曲（琴、笛、太鼓），依情境換曲：村子白天、夜晚、野外、戰鬥、頭目戰。環境音有瀑布、河流、海浪、風、雨、白天的鳥叫、夜裡的蟲鳴。選單「系統」可以分別調整背景音樂、音效、環境音的音量。

### 成長

- **等級**：擊敗敵人得到經驗值。每升一級獲得 3 能力點、1 忍術點，HP 與查克拉回滿。
- **階級**：下忍 → 中忍（Lv5）→ 上忍（Lv10）→ 精英上忍（Lv15）→ 傳說忍者（Lv20）
- **能力值**：體力（HP）、查克拉（上限與回復）、體術（體術與苦無傷害）、忍術（忍術傷害）、敏捷（移動速度）
- **查克拉屬性**：Lv3 選第一個、Lv12 選第二個。各屬性有兩招，用忍術點學習。
- **熟練度**：同一招每用 10 次升一星（最多五星），傷害 +6%、耗費 -4%。
- **金錢與商店**：敵人會掉「兩」。廣場東側的忍具店賣傷藥、兵糧丸與裝備；西側鈴屋拉麵 20 兩一碗，HP 與查克拉全滿。
- **存檔**：自動存在瀏覽器（每 15 秒、升級與購買時）。

### 任務與劇情

首領塔前的**任務板**可以接任務（一次最多 3 個），完成目標後回任務板回報領取報酬。旁邊的**天守大人**會帶出主線劇情：叛忍「黑鴉」偷走了村子的禁術卷軸。

| 等級 | 任務 | 目標 | 開放條件 |
|---|---|---|---|
| D | 修行的成果 | 攻擊訓練木樁 20 次 | — |
| D | 巡視白鷺川 | 前往白鷺川 | — |
| D | 驅逐野狼（可重複） | 擊敗野狼 5 隻 | — |
| D | 拉麵外送 | 和南方道路的旅人說話 | Lv2 |
| C | 山賊討伐（可重複） | 擊敗山賊 6 名 | Lv4、完成驅逐野狼 |
| C | 森林之王 | 擊敗狼王 | Lv5、完成驅逐野狼 |
| B | 流浪忍者的情報（可重複） | 擊敗流浪忍者 3 名 | Lv7、完成山賊討伐 |
| A | 黑鴉 | 擊敗黑鴉 | Lv10、完成流浪忍者的情報，向天守大人接取 |
| C | 海岸的海賊（可重複） | 擊敗海賊 4 名 | Lv5、完成山賊討伐 |
| C | 霧鳴瀑布的傳說 | 穿過蒼龍峽，抵達霧鳴瀑布 | Lv6 |
| B | 峽谷的崖山賊（可重複） | 擊敗崖山賊 5 名 | Lv8、完成霧鳴瀑布的傳說 |
| B | 古樹之森的魔狼（可重複） | 擊敗魔狼 6 隻 | Lv10、完成森林之王 |

村民可以對話，會給你遊戲提示。頭上有「！」的 NPC 有新消息。村民有作息：傍晚陸續回家，早上再出門；晚上只剩提著燈籠巡夜的中忍。街上還有閒晃的貓狗（狗會跟著你走一段，跑太快會嚇跑貓）、廣場上啄食的麻雀（靠近就飛走），以及隨風飄動的晾曬衣物。

### 敵人

| 敵人 | 出沒地點 | 特徵 |
|---|---|---|
| 野狼 | 西邊森林 | 速度快、成群行動，打一隻整群都會撲上來 |
| 山賊 | 南方道路與郊外 | 揮刀前會舉高，動作慢但很痛 |
| 流浪忍者 | 河邊、峽谷、高原 | 會丟苦無，也會用替身術閃避 |
| 海賊 | 潮見海岸 | 揮刀很重 |
| 崖山賊 | 蒼龍峽、雲上高原、東方原野 | 近身揮大刀，遠距離丟苦無 |
| 魔狼 | 古樹之森、雲上高原 | 比野狼大、更快、更痛，成群行動 |
| 訓練木樁 | 村子大門外 | 不會反擊，用來練習 |
| **狼王**（頭目） | 幽冥森林最深處 | 體型巨大，會嚎叫召喚狼群 |
| **黑鴉**（頭目） | 蒼龍峽入口 | 扇形苦無、火球，血量剩一半時叫出影子分身 |

頭目在小地圖上是金色圓點，只有重擊（三連擊最後一下、忍術擊退）或暈眩才能打斷它們的動作。

敵人出手前身體會閃紅光，看到就用替身術閃開。

## 專案結構

```
src/
├── main.js          遊戲主迴圈
├── data/theme.js    世界觀設定：地名、角色名、招牌文字、主角外觀
├── core/            輸入、數學、畫質設定、文字貼圖
├── combat/          戰鬥：體術、苦無、結印與忍術（jutsu.js）、敵人 AI、分身
├── progress/        成長：等級、能力值、道具、存檔
├── quests/          任務表與任務進度
├── render/          賽璐璐材質、描邊後製、風
├── world/           地形（heightmap.js 是地圖配置）、水、瀑布、草、樹、村莊、街景、驛站、天空、碰撞
├── audio/           即時合成的音效（sfx.js 基本聲音與腳步、sounds.js 音效配方、ambience.js 環境音、music.js 背景音樂）
├── player/          主角控制、角色模型與動畫、鏡頭
├── npc/             村民、街頭生活（貓狗、麻雀、晾衣）
├── fx/              粒子特效
└── ui/              介面、小地圖、觸控操作
```

### 自訂世界觀

所有名稱集中在 `src/data/theme.js`。想在自己電腦上換成別的設定，複製成 `src/data/theme.local.js`，只寫要改的欄位即可。這個檔案列在 `.gitignore`，不會被上傳；網址加上 `?original` 可以暫時切回預設設定。
